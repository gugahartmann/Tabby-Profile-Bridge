# Tabby Profile Bridge v0.2.3

**Your connections, across terminals.**

Tabby Profile Bridge is a community plugin for importing, exporting and converting SSH/Telnet connection profiles between [Tabby](https://github.com/Eugeny/tabby), **MobaXterm** (`.mxtsessions`) and **CSV**. It preserves nested folder hierarchies while giving users control over which connections and usernames are shared.

### What's included

- **Import and export both ways:** CSV and MobaXterm sessions, including custom SSH ports, IP addresses, hostnames and selected usernames.
- **Preserve nested folders:** select complete profile groups or individual connections; add one top-level folder on export or a different destination folder for each imported file.
- **Conflict-aware import:** preview incoming profiles and choose **Keep / skip**, **Add as new** or **Replace existing** for each.
- **Bulk username conversion:** update usernames in incoming sessions before applying them to Tabby.
- **Privacy-first exports:** usernames are opt-in; passwords, private key contents/paths, login scripts and proxy commands are intentionally excluded.
- **English and Portuguese:** language follows Tabby's selected locale, including automatic language detection.
- **Built-in version label:** `by gugahartmann · v0.2.3` in the plugin interface.

### Tested workflow

A user successfully tested exporting sessions from Tabby to MobaXterm and importing them back into Tabby. Compatibility with advanced, terminal-specific settings may vary and should be reviewed before overwriting existing profiles.

### Getting started

Install **`tabby-profile-bridge`** using a supported Tabby plugin installation method. Open **Settings → Profile Bridge**, select **Export** or **Import**, choose the target format and review the selected sessions before applying changes.

**Back up your Tabby configuration before replacing existing profiles.** The plugin will not automatically replace matching connections.
